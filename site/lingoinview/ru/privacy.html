Политика конфиденциальности

Действует с 18 ноября 2026 года. Разработчик LingoInView — danilfg.

Расширение читает субтитры YouTube и контекст видео для перевода выбранных слов и создания карточек. Слова, переводы, контекст, названия и идентификаторы видео, временные метки, история обучения, настройки и словари хранятся локально в хранилище Chrome и IndexedDB.

Каталоги и пакеты словарей загружаются из GitHub и GHCR, которые получают обычные сетевые данные, например IP-адрес и запрошенные ресурсы. Встроенный переводчик Chrome может загружать языковые модели согласно правилам Google. Слова и субтитры не отправляются на сервер переводов или аналитики разработчика. Внешние ссылки открываются по запросу пользователя.

В текущей версии нет аккаунтов, аналитики разработчика, рекламного отслеживания и облачной синхронизации. Разработчик не продаёт данные и не передаёт их рекламодателям. Экспорт выполняется по запросу; пользователь выбирает, куда его передавать.

Данные остаются на устройстве до удаления или деинсталляции. Резервные копии JSON и другие экспортируемые файлы могут содержать историю обучения и контекст видео; храните их безопасно.

Сайт не использует собственной аналитики, отслеживающих cookies или форм регистрации. GitHub Pages может обрабатывать обычные журналы хостинга. У сторонних сервисов собственные политики.

По вопросам свяжитесь с разработчиком через профиль GitHub ниже. Политика будет обновлена до внедрения новых функций сбора данных.
