# KOReader dictionaries

[Original project](https://github.com/DanielGregorini/koreader-dicts) · [Main release](https://github.com/danilfg/dicts/releases/latest)

The project currently distributes 74 bilingual StarDict ZIPs from the independent KOReader dictionary collection. Each original ZIP retains its own `LICENSE` and `ATTRIBUTION`; terms differ by language pair. Only the GitHub release asset filename is prefixed `koreader--`. The workflow checks the original author's release and can fall back to the maintainer's separate [KOReader mirror](https://github.com/danilfg/koreader-dicts/releases).

Dicts distributes these archives without guaranteeing linguistic correctness or implying an affiliation with the original publisher.
