# Kaikki / Wiktionary

[Original textual extractions](https://kaikki.org/dictionary/rawdata.html) · [Latest unified release](https://github.com/danilfg/dicts/releases/latest)

The workflow mirrors discoverable textual Wiktionary editions as independent `kaikki--*` assets in a dated release. Original large files may be split into numbered parts with the exact URLs and checksums in `kaikki--SOURCE-MANIFEST.json` (or `SOURCE-MANIFEST.json` in older releases).

The main dictionary release additionally contains a **limited study index** of selected English expressions and definitions, **not** every Wiktionary entry or language. These are distinct deliverables and require different readers.

Applicable Wiktionary text generally uses CC BY-SA terms; respect original contributors, source/licensing and modification notices. Individually licensed media are not included as standalone audio/image archives.

## Versioned distribution

Each new dated release includes all eight source families. Find this collection using the `kaikki--` asset prefix and release-wide `RELEASE-MANIFEST.json`. Original source licenses, credits and per-source notices remain separate; older source-specific snapshots are retained for historical compatibility.
