# Tatoeba — complete multilingual textual exports

The full-text mirror copies the official [Tatoeba export archives](https://downloads.tatoeba.org/exports/) for the **entire multilingual sentence collection** (sentences, detailed author metadata, translation links, CC0 data and base relationships), not merely English/Russian and not capped at 30,000 examples. They are published as independent **raw-tatoeba-*** GitHub Releases, with a manifest, SHA-256 and source attribution. **Audio is excluded.**

The lightweight `enrichment--en-ru.json.gz` file may still contain a *selected* English/Russian set for browser performance; it must not be confused with the full raw corpus now available for download.

Text content can be CC BY 2.0 France or individually marked CC0; preserve attribution and licensing per sentence. The aggregator does not create or editorially verify contributed examples.
