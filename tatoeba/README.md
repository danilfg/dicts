# Tatoeba text corpus

[Publisher downloads](https://tatoeba.org/en/downloads) · [Latest unified release](https://github.com/danilfg/dicts/releases/latest)

The raw pipeline mirrors the publicly available multilingual **text** sentence and translation-link exports, including applicable attribution/CC0 metadata. **Audio is excluded.** The exact files and SHA-256 are documented in the raw release manifest.

The main dictionary release's browser study index includes a **selected EN–RU example set**, not the complete Tatoeba collection. These two formats should not be confused.

Text is generally CC BY 2.0 France, with some sentences expressly made available under CC0. Preserve source URLs, authors when provided, sentence/translation IDs and the correct applicable rights.

## Versioned distribution

Each new dated release includes all eight source families. Find this collection using the `tatoeba--` asset prefix and release-wide `RELEASE-MANIFEST.json`. Original source licenses, credits and per-source notices remain separate; older source-specific snapshots are retained for historical compatibility.
